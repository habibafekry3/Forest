# 🌐 LANDING PAGE

A dynamic and responsive Landing Page project featuring a dynamic navigation bar and smooth scrolling functionality, built with HTML, CSS, and JavaScript.

---

## 🚀 Quickstart / Demo

* You can see the live demo from here: [Live Demo Link](https://habibafekry3.github.io/Forest/)
* **OR** Run it locally: Open the project folder using VS Code, right-click on the `index.html` file, and choose **"Open with Live Server"**.

---

## 🌟 Features & Usage

1. **Dynamic Navigation Menu:** Includes a navigation bar with five sections: *Home, Birds, Plants, Animals, and Lakes*, which are dynamically generated using JavaScript.
2. **Smooth Scrolling:** Clicking on any link in the navigation bar smoothly scrolls the page to the corresponding section.
3. **Active State Highlighting:** While scrolling, the section currently visible on the screen and its corresponding link in the navigation bar are automatically highlighted.
4. **Scroll-to-Top Button:** Includes a functional button for smooth and fast scrolling back to the top of the page.
